# PULSE GRID

Jeu web d'arcade rythmique : un carré lumineux sur un damier 5x5 doit esquiver des cases qui explosent en rythme avec une musique électro procédurale.

Stack : Vite + TypeScript, Canvas 2D, Web Audio API, Vitest.

```
npm install
npm run dev     # serveur de dev
npm test        # tests unitaires
npm run build   # typecheck + build de production
```
